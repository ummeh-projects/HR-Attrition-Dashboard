# HR Employee Attrition Dashboard
## Project Overview 
This project features an interactive HR Attrition Dashboard created using Microsoft Excel to analyze key factors influencing employee turnover.
## Key Insights & Visualizations
* **Job Role vs. Attrition:** Identifies high-turnover roles like Sales Executives and Research Scientists.
* **Overall Attrition Rate:** Highlights the total proportion of employees leaving the organization.
* **Monthly Income & Satisfaction:** Analyzes the correlation between compensation, job satisfaction, and turnover.
  ## Tools Used
  * Microsoft Excel (pivort Tables, pivort Charts, Data Analysis)
  * GitHub (Project Hosting & protfolio)
